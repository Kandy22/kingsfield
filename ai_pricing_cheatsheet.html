Antigravity Mac Fix

Why it failed + how to fix it

WHYMost failures are: (a) macOS Gatekeeper blocking unsigned app, (b) old version cached, (c) signing into a Google account with billing issues. The app requires macOS Monterey 12+ and Chrome installed.
OPT ADownload fresh from antigravity.google/download → click Download for Apple Silicon (.dmg, ~182MB). Open .dmg, drag to Applications. On first launch: right-click → Open (bypasses Gatekeeper). Sign in with a clean Google account, NOT the one with billing issues.
OPT BHomebrew CLI version is lighter and more reliable: brew install --cask antigravity-cli. Requires macOS 12+. Terminal-only but no Gatekeeper issues. Run with antigravity.
OPT CSkip Antigravity entirely for Wingman. Claude Code does the same job for Python/audio builds and you already have it. Antigravity is more useful for Google-native deploys (Cloud Run, Firebase) later.
BILLINGYour Google billing issue (Play/One/AI Cloud mix): add a $10 credit to a new separate Google Cloud project via console.cloud.google.com. Use project-scoped billing to isolate it from the old mess. AI Studio API calls bill to this project, not the legacy account.
